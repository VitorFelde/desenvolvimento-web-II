# Week 03 — Operators and calculations

**Target time:** 5–7 hours  
**Goal:** Perform calculations and format results.

## Learn
- Arithmetic operators
- precedence
- modulo
- type conversion
- number formatting.

## Exercises
- [PHP05 — Rectangle calculator](exercise-05-rectangle-calculator.php)

## Suggested sessions
- **Session 1 (45–75 min):** Read this page and attempt Exercise A without copying a solution.
- **Session 2 (45–75 min):** Run it, test the listed cases, and explain the code.
- **Session 3 (45–75 min):** Attempt Exercise B.
- **Session 4 (45–75 min):** Debug, improve names/readability, and test edge cases.
- **Session 5 (30–60 min):** Review the hardest part or retry without looking at hints.

## Exit test
Solve a small calculation problem without copying an example.

## Rules for asking for review
Send the exercise ID and your code in the dedicated PHP coding chat. Include any error message and say what you expected to happen. Do not mark the topic mastered until you can explain your solution and make a small variation yourself.

If a task takes longer than planned, use the next session to review it rather than rushing ahead.
