# PHP — 24-week practice roadmap

This folder is your coding workbook. Open it in VS Code and work directly in the exercise files. The problem statement and hints are inside each `.php` file as comments; the solution area is intentionally blank.

## Rules
- Study for **5–7 hours per week**. The schedule is a guide, not a deadline.
- Attempt the task before asking for a complete solution. Ask for a hint if stuck.
- Run each file and test the cases in its comments.
- Send the code here in this chat for review. I will check correctness, explain mistakes, and decide with you whether to advance or practice more.
- A file being completed does not automatically mean the topic is mastered.
- Do not put passwords or real database credentials in GitHub.

## Suggested weekly rhythm
1. Day 1: read the week's README and attempt Exercise A.
2. Day 2: debug Exercise A and explain the code in your own words.
3. Day 3: attempt Exercise B.
4. Day 4: test edge cases and improve naming/readability.
5. Day 5: review or retry anything that still feels unclear.

## How to run
From a terminal, check PHP is installed with `php -v`. Run a single exercise with:

```bash
php path/to/exercise.php
```

For exercises involving HTML forms, run the local PHP development server from the relevant folder using `php -S localhost:8000`; see that week's README and keep the related HTML file beside the PHP handler. Database weeks require a local MySQL/MariaDB setup and a database you create yourself.
